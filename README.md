# Cobblemon Unyielding

**Cobblemon Unyielding** is a large **Minecraft 1.21.1 NeoForge Cobblemon adventure server and modpack** built around Pokémon, Origins, exploration, progression, gyms, quests, dungeons, custom content, Fakemon, and hundreds of carefully selected mods.

> **Development status:** Work in progress / active testing. Features, mods, configs, balance, and progression may change while the server is being developed.

## Server

**Address:** `play.cobblemonunyielding.win`

## Main Features

- Cobblemon Pokémon catching, training, battling, and exploration
- **Origins and custom character abilities**
- Player Gym Leaders and gym challenges
- Fakemon and additional Pokémon content
- Large-scale exploration with many biomes and dimensions
- Dungeons, structures, bosses, and adventure content
- Quests and progression systems
- Custom server content and balance changes
- A large NeoForge modpack with hundreds of mods
- Multiplayer-focused gameplay and community events

- **Mod Loader:** NeoForge
- **Cobblemon:** 1.8.1

## Installation — Modrinth

Use this method if you downloaded the `.mrpack` version from GitHub Releases or Modrinth.

1. Download the latest `Cobblemon-Unyielding.mrpack`.
2. Open the **Modrinth App**.
3. Choose **Create new instance** / **Import from file**.
4. Select the downloaded `.mrpack`.
5. Let Modrinth finish installing the pack.
6. Launch **Cobblemon Unyielding**.
7. Join the server at `play.cobblemonunyielding.win`.

## Installation — CurseForge (Manual ZIP)

**The public CurseForge project is still awaiting approval.** You can still install and play Cobblemon Unyielding through the CurseForge App using the downloadable ZIP from the GitHub Releases page.

Download:

`Cobblemon Unyielding (B)-1.0.6.zip`

Then:

1. Open the **CurseForge App**.
2. Select **Minecraft**.
3. Choose **Import** / **Import Profile**.
4. When the file picker opens, change the file-type filter to **All Files** if the ZIP does not appear.
5. **Do not leave the picker on the CurseForge-only file filter** if it hides the download.
6. Select `Cobblemon Unyielding (B)-1.0.6.zip`.
7. Let CurseForge import and install the modpack.
8. Launch **Cobblemon Unyielding**.
9. Join the server at `play.cobblemonunyielding.win`.

> This ZIP is the **manual CurseForge installation option** while the official CurseForge project is still waiting for approval. Once the public project is approved, players will also be able to install it normally from the CurseForge project page.

> The `.mrpack` file is for **Modrinth**. The `.zip` file is for the **CurseForge manual import** method.
