# Cobblemon Unyielding

**Cobblemon Unyielding** is a large **Minecraft 1.21.1 NeoForge Cobblemon adventure server and modpack** built around Pokémon, Origins, exploration, progression, gyms, quests, dungeons, custom content, Fakemon, and hundreds of carefully selected mods.

> **Development status:** Work in progress / active testing. Features, mods, configs, balance, and progression may change while the server is being developed.

## Server

**Address:** `play.cobblemonunyielding.win`

## Main Features

- Cobblemon Pokémon catching, training, battling, and exploration
- **Origins and custom character abilities**
- Player Gym Leaders and gym challenges
- Fakemon and additional Pokémon content
- Large-scale exploration with many biomes and dimensions
- Dungeons, structures, bosses, and adventure content
- Quests and progression systems
- Custom server content and balance changes
- A large NeoForge modpack with hundreds of mods
- Multiplayer-focused gameplay and community events

## Modpack

- **Minecraft:** 1.21.1
- **Mod Loader:** NeoForge
- **Cobblemon:** 1.8.1
- **Current testing branch:** 1.0.6 beta

The modpack is distributed as a `.mrpack` for easy installation through the Modrinth App.

## Downloads

Official downloadable builds will be posted on the **GitHub Releases** page:

https://github.com/WeepingAngeIs/Cobblemon-Unyielding/releases

The pack is also being prepared for distribution through **Modrinth** and **CurseForge**.

## Installation

1. Download the latest `Cobblemon-Unyielding.mrpack` from the Releases page.
2. Open the **Modrinth App**.
3. Import the `.mrpack` file.
4. Launch the installed instance.
5. Join `play.cobblemonunyielding.win`.

## Testing Notice

Cobblemon Unyielding is still being actively tested. Players may encounter bugs, balance changes, mod updates, configuration changes, or temporary compatibility issues.

Feedback and bug reports are welcome while development continues.
